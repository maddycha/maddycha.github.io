    widget

    to change the color of the text and arrows, add this code to your css.

    #rhythmring *{ color: [INSERT COLOR]; fill: [INSERT COLOR]; }

    to change the width of the widget, add this code to your css.
    (note: min-width is set to min-content, would not suggest changing this!)

    #rhythmring{ width: [INSERT WIDTH]; }
